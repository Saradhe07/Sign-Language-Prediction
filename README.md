# 🖐️ Sign Language Prediction for Autism Spectrum Disorder

Hybrid Deep Learning + Computer Vision Based Sign Translation System

📌 Overview

This project aims to revolutionize communication support for individuals with Autism Spectrum Disorder (ASD) by providing a real-time Sign Language Detection and Translation System.

Using a hybrid deep-learning model combining CNN, LSTM, MediaPipe, and Computer Vision, the system recognizes hand gestures and converts them into text and speech output.

🚀 Features

1) Real-time sign gesture tracking using MediaPipe Hands / OpenCV

2) Hybrid deep learning architecture using

3) CNN for spatial feature extraction

4) LSTM / GRU for sequence prediction

5) Multi-class gesture recognition

6) Text & speech output

7) Dataset augmentation and gesture preprocessing

8) Modular, scalable architecture

9) Easy integration with mobile/IoT devices

🧠 Tech Stack

Programming: Python

Frameworks: TensorFlow / Keras, PyTorch 

Computer Vision: OpenCV, MediaPipe

ML: Scikit-Learn

Visualization: Matplotlib, Seaborn

Deployment: Flask / Streamlit

💡 Inspiration

People with Autism often rely on visual gestures for communication.
This project is designed to empower them with accessible, fast, and intelligent sign recognition technology.
